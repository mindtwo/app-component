Unplugin defineAppComponent Usage

This example demonstrates the use of the defineAppComponent un provided by the Vite plugin.

The un transforms the component definition at build time, simplifying the syntax for creating app components.

Usage:

// Instead of:
import { AppComponent } from '@mindtwo/app-component';
const component = AppComponent.create({...});

// You can use:
const component = defineAppComponent({...});
